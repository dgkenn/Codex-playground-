# LSH Transitional-Year Intern Call Schedule — Oct 2026 → Jun 2027

Call schedule for the interns rotating through **Lemuel Shattuck Hospital (LSH)**,
continuing the provided **July–September 2026** schedule through the end of the
academic year. Each day's team is **2 LSH interns + 1 BMC-South/Brighton intern
+ 1 Lahey intern**, covering Long Call, Short Call, Night Float and the Saturday
24-hour shift.

## Files

| File | What it is |
|---|---|
| `schedules/TYP_<Month>_<Year>.xlsx` | One file per month (Oct 2026 – Jun 2027), same layout as the Jul–Sep sheets. |
| `schedules/TYP_Intern_Schedule_Oct2026-Jun2027.xlsx` | All nine months in one workbook (one tab per month). |
| `RULES_COMPLIANCE.md` | Rule-by-rule audit — every rule checked programmatically; what passes and the few unavoidable compromises. |
| `generator/` | The scripts that build (`gen.py`) and independently verify (`validate.py`, `report.py`) the schedule, and export the workbooks (`export.py`). |

Each monthly sheet keeps the original columns — **DAY · DATE · Long Call · Short
Call · Night Float / Sat 24h** — plus a footer listing that month's LSH, BMC-S,
Lahey and senior-resident rotators. Saturdays are shaded orange and Sundays yellow.

## How it was built

The schedule is generated by a constraint-aware program (not by hand), then
checked by a **separate** validator so the rules are verified independently of
how they were produced. Key rules encoded (from *Scheduling Interns at LSH* and
*Principles*):

- 1 Long Call/day (~Q4, Sun–Thu 7a–6p, Fri 7a–7:30p); **no LC the day before a 24h shift, never on call two days running.**
- Short Call 2 interns weekdays / 1 Thursday / 0 weekends, **7a–4p (does *not* leave at noon).**
- Night Float one intern Sun→Fri consecutive; none Saturday.
- Saturday 24h one intern, off the next day; Thursday the preferred day off (only one off at a time).
- New BMC-S/Lahey interns never start on Long Call or Night Float (they begin on Short Call).
- ≥1 day off every week for everyone.

## Priorities applied

1. **Dr. Kennedy** — schedule optimized within the rules: minimum call (exactly 1 NF week + 1 Saturday in each of Nov & Mar), **Nov 7–8 weekend off**, Thanksgiving Day off (he volunteered for the Thanksgiving Saturday 24h so Wise wasn't stuck with holiday duty), Thursdays off, no rough back-to-backs.
2. **Shattuck (LSH) interns are favored over outside (BMC/Lahey) rotators** — every LSH intern gets exactly one NF week and one Saturday per month (never doubled); all overflow (2nd NF weeks, 2nd Saturdays) is absorbed by outside rotators.

## Regenerating

```bash
cd generator
python3 gen.py        # builds the schedule -> assign.pkl
python3 validate.py   # independent rule check (0 hard errors expected)
python3 report.py     # writes RULES_COMPLIANCE.md
python3 export.py     # writes the .xlsx files
```

Roster, rotation blocks and all rules live at the top of `gen.py`; edit there
and rerun to reflect roster changes.
