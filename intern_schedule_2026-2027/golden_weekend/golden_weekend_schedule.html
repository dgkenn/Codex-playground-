Golden Weekend Schedule — Mockup (Sep 1 – Dec 31 2026)

An experimental alternative to the Q4 “march” model. Every intern gets one true golden weekend (Saturday + Sunday both off) plus one extra weekend day off per 4-week cycle, built from four rotating weekly modules — Golden (Day Mon–Fri, off Sat/Sun), Nights (night float Mon–Sat, off Sun), Heavy (Day Mon/Tue/Wed, off Thu, Day Fri/Sat, 24H Sunday), and Steady (off Monday, Day Tue–Sat, Sunday off only when a senior is on service that day). The hard floor: never fewer than 2 note-writers on any single day (18-patient cap → ≤9 notes each). This is a visualization of the format, not the production schedule — see SPEC.md and golden_gen.py in this folder for the full build logic.

Golden (day rounder, off Sat/Sun) Nights (night float, off Sun) Heavy (Sun 24H, off Thu) Steady (off Mon, off Sun if senior rounds) OFF (that person’s day off, whatever module they’re in) ★pinned intern request orange row = Saturday · yellow row = Sunday · each cell = duty · module

Coverage check

  • OK Every single day, Sep 1 – Dec 31 2026, has ≥ 2 note-writers (Day/24H duty, senior counts Sunday).
  • OK Every week the 4 slots (LSH1, LSH2, Lahey, BMC) hold 4 distinct modules (Heavy→Steady→Nights→Golden base rotation, offset per slot).
