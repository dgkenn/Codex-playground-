# LSH Intern Time-Off Requests — Scheduler Working Sheet

**Sep 1 2026 – Jun 23 2027.** This sheet is written to give the schedule maker
everything needed to make decisions **without recording why anyone asked.**
No reasons appear here, by design. See *Privacy* at the bottom.

---

## How to read this

**Tier — how much the date can move**

| | | |
|---|---|---|
| **H** | Hard | The date cannot move. Schedule around it. |
| **S** | Soft | Strong request. Accommodate if it doesn't break the march; the intern has indicated they'll arrange a swap themselves if not. |
| **P** | Preference | Pattern or quality-of-life. No specific date at stake. |

**Flex — what a partial accommodation looks like** (so a "no" can still be a "mostly")

| | |
|---|---|
| **FULL** | Needs the full day(s) genuinely off |
| **SC-OK** | A short call is acceptable instead of a full day off |
| **NO-NIGHTS** | Fine to work the day; the ask is only to be off night float |
| **CORE** | Only part of the range is critical — the core dates are marked |

**Fixed-by — who controls the date** *(the privacy-preserving substitute for a reason)*

| | |
|---|---|
| **EXT** | Set by someone outside the program. The intern cannot move it. |
| **SELF** | The intern could in principle shift it. |
| **—** | Not applicable / not asked. |

**Confidence** — `doc` = firmness is on record. `prop` = **proposed by me, needs your confirmation.**

## Privacy

**What this sheet does.** It carries the three facts a scheduler actually needs —
*how hard is the date*, *what partial accommodation still works*, *can the intern
move it* — and nothing else. `EXT` tells you a real external commitment exists and
the intern has no control over the date. That is the entire decision-relevant
content of a reason, without the reason.

**Recommendations going forward:**

- **Don't collect reasons at intake.** Ask for dates, tier, flex, and fixed-by.
  A reason that was never recorded cannot leak, be forwarded, or sit in a shared
  drive for three years. This is the single highest-value change.
- **If a reason is volunteered, keep it with the PD only** — never in the
  scheduler-facing sheet, and never in a shared file.
- **No free-text notes in the shared version.** Free text is where identifying
  detail creeps back in.
- **Drop supporting detail once the schedule is locked.** The dates need to
  persist; nothing behind them does.
- **One residual limit, stated plainly:** a specific date marked **H / EXT** is
  still somewhat inferable from the calendar alone — a single Saturday in
  September reads a certain way to anyone who looks. This schema removes the
  confirmation, not the inference. An intern who wants more discretion than that
  should raise it with the PD directly, and the answer is usually to widen the
  request to a range rather than to hide it.

**Not covered here:** rotation-grid facts (who is on elective, vacation, or ED in
a given month) are used by the audit for night-float transition checks. Those are
assignment data, not time-off requests, and are documented separately in
`ACCOMMODATIONS.md`.
