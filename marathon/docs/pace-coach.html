Before you go

Each button plays exactly that one sound, so you can learn them one at a time. Sample tone is the single note you hear on coming back on pace — press that first to set the volume against your music.

Start Apple Music first, then run the checks. Safari can't ask iOS to mix with other audio the way a real app can, so your music may duck or pause when a tone plays. Thirty seconds standing still tells you which — better than finding out at minute twelve.

How it went

Beats per mile and efficiency factor are the two that track fitness: the same pace at a lower heart rate is progress and nothing else. Both need the armband, and both are only comparable between similar sessions.

Saved sessions

—

Every session is written to this phone while it runs, not just at the end. A page that reloads mid-run — which iOS does by itself to a backgrounded tab, with no warning — used to take the whole recording with it.

Session log

The session copies to your clipboard rather than downloading — a browser that will not save a file leaves you with a run you cannot get off the phone. Paste it into the chat and it imports with cli import. Copy diagnostics does the same for the build id, what this browser can do, and the last forty log lines: that is what to send when something does not work. If the browser has no clipboard, both put the text on the page instead.
