Then what

Download the file and run:

python -m marathon_engine.cli import verity-session.json --save

This format carries the accelerometer, which a Polar Flow TCX export does not. That matters: without it the not-worn and frozen-heart-rate detectors cannot run at all, and sensor health comes back "partial". With it you get the full check.
