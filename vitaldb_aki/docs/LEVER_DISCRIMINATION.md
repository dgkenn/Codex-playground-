# Fluid-vs-pressor lever discrimination (powered) + concordance->outcome

Does the A-line tell you WHICH lever (fluid vs pressor)? Tests the two axes -- PPV (preload-responsive->fluid) and diastolic tone (vasoplegic->pressor) -- at large N, and whether matching the A-line-indicated lever associates with less organ injury.

- Cases with morphology axes: **521** (both PPV+tone: 433).
- **Orthogonality (PPV vs tone):** {'r': -0.09, 'ci': [-0.184, 0.003], 'n': 433} (|r|<0.3 = independent decision axes).
- **Lever quadrants:** {'fluid_indicated': 112, 'pressor_indicated': 90, 'mixed_ambiguous': 231}; decision-relevant fraction 0.47.
- **Concordance -> outcome** (n=433): composite RD -0.074 [35, 33], renal RD 0.006, hypoperfusion RD None.
  _negative RD (concordant LOWER injury) = recoverable benefit from following the A-line lever. Confounded: clinicians may already act on PPV/tone -> null expected; a clear negative RD is the strong signal._

## Verdict
Lever axes INDEPENDENT (PPV vs tone r=-0.09 [-0.184, 0.003], n=433); 0.47 of patients have a clear single A-line lever. Concordance->outcome: composite RD -0.074 (n=[35, 33]).

## Caveats
- Actual fluid/pressor lean uses end-of-case TOTALS (no timing) -> coarse; the concordance test is exploratory. Confounding by indication runs BOTH ways (clinicians may already read the A-line) -> a null concordance benefit is consistent with 'already optimal'; only a clear negative RD is decisive. Single-centre. Needs a trial for a causal lever-guidance claim.
